# Ches


## Requirements
- texlive tool and Times New Roman font if you want documentation.

## Building project
```bash
    $ches> gcc ./nob.c -o nob
    $ches> ./nob
```
## Resources used
- [onlinegantt.com](https://www.onlinegantt.com/#/gantt) for Gantt Chart
- [draw.io](draw.io) for Diagrams

---

**This Project attempts to create a chess application with Online multiplayer and AI Offline players. This porject is developed in partial fullfilment of the requirement for course in the Bachelor of Computer Science, 6th semester under Faculty of Humanities and Social Sciences, Tribhuvan University.**
